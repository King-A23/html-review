GETTING STARTED

把意见，说到点上。

工作区会按进度提示下一步，随时可以回来继续。

  1. 01

    阅读，留下意见

    打开或拖入 HTML、DOCX 或 PDF。选择文字、图片等目标，填写并保存批注；也可以直接写整体意见。HTML 带本地图片、样式或脚本时，请导入文件夹。

  2. 02

    交给你使用的 agent

    点击「交给 agent」，复制任务并附上原文档，或下载交接包，把 ZIP 附给 agent。材料准备好后仍需你发送。「保存副本」用于备份和继续审阅。

  3. 03

    读取返回文件，检查修改

    点击「agent 已返回文件」。读取修改后的文档更新预览，导入处理记录 JSON 更新批注状态；两份文件先读入哪一份都可以。只有 JSON 时正文仍是旧的。读取文档后再「逐条复核」，原意见和完成记录会保留。

刷新恢复的是本机工作区。原文件被修改后，需要重新读取；顶部重载按钮也可读取最新原文件与资源，保留批注和草稿。首次可能需要选择原文件或文件夹。长期保留或跨设备使用，请保存完整副本。

怎样选择批注范围？

文字模式拖选原文；元素模式点击目标，也可向外选择父级。HTML 单页对应已有的幻灯片、打印页等分页区块，可点击或从列表挑选；识别 data-page、data-slide、print-page、slide 以及多个 page 区块，没有分页结构时用整体或元素。PDF 区域模式拖出矩形，单页对应实际页码；扫描页改用区域框选。DOCX 支持文字、元素和整体。取消选择时已填写的意见会保留。

恢复批注与复核位置

完整 HTML 工作区副本可离线继续编辑，压缩副本需先解压。轻量批注不含原文档；打开 DOCX / PDF 轻量 JSON 后选择哈希匹配的原文件可恢复。HTML 轻量 JSON 需配合原 HTML 和资源交付。

已关联文件夹时，重载会同时读取原文件旁同名处理记录，也可单独导入。没有处理记录也可以检查新文档，完成状态保持不变。编辑已完成意见会重新进入待处理。

位置检查详情可以展开。遇到无法确认或多个候选时，核对对照再明确确认，或重新选择位置；原定位保留作记录。定位检查与逐条复核都不会自动标记完成。批注支持撤销重做。

支持范围与文件限制

DOCX 连续内容预览不还原 Word 页码与原生排版，页眉页脚和复杂图形不保证呈现，Word 原生批注不转为任务。PDF 按原页预览，首版不做 OCR。工具不编辑原文档，查找、位置检查和文件读取可取消。

仅打开可信 HTML，页面脚本可运行；服务器接口、嵌套 iframe、ES 模块等可能无法完整重现。原始 HTML / DOCX / PDF 上限 20 MiB，副本上限 100 MiB；目录上限 50 MiB、500 个文件。DOCX 解压内容限 100 MiB、3000 项，转换超过 30 秒中止。存储不可用时请保存副本。

系统文件选择器无法打开时，可使用兼容方式。兼容方式重载时需要重新选择原文件。
