## 实际 DOCX 往返

生成三页《澄川科技2026年前三季度经营报告》，明确公司和数据虚构。包含跨样式摘要、两处重复短句、双行合并表头、季度金额、嵌入柱状图、图注、显式分页和脚注。通过实际文档预览保存五条意见，下载轻量 JSON、完整工作区及交接 ZIP。

独立 `gpt-6.1-sol` agent 仅接收这个 ZIP，不读取产品源码、测试、原件生成脚本或此前对话。其实际修改返回的 DOCX，并生成符合原始 ID、revision 和更新时间 guard 的结果文件：

| 意见 | 返回结果 | 独立核验 |
| --- | --- | --- |
| 缩短摘要 | resolved | 两句话；8.1 亿元、20%、0.90 亿元及数字加粗保留。 |
| 删除临时免责声明 | resolved | 只删目标段落，原有虚构数据说明和脚注保留。 |
| 表格表头补单位 | resolved | 仅两处增加“（亿元）”；金额、合并与样式保持。 |
| 营收图改橄榄绿 | resolved | 全部 214,065 个 #178C92 像素替换为 #50663E，其他像素逐一一致；1440×760 和文档插入尺寸保持。 |
| 按最新品牌规范改图注 | open | ZIP 不含品牌规范，明确报告缺少字体 / 字号材料，未猜测或冒充完成。 |

原件 SHA-256：`4162960d8ad2f27d657a9cdf4008d2ee9ba70559eba7c3e65232756c41e5b342`。返回件 SHA-256：`91e0a2237dad1c72e74c0bde2b4ac22aa8c2119d984d404878169f01a9de58a1`。原件与交接包内快照逐字节一致；返回仅改变 `word/document.xml` 和 `word/media/image1.png`，其余部件字节一致。另一个独立 agent 的只读验证通过 25 项检查。

原件和返回件经 bundled LibreOffice 渲染，三页逐页检查。首次返回渲染缺少中文字体，通过仅用于 QA 的临时字体配置重渲，未修改系统字体或 DOCX。本机 Microsoft Word 通过 computer use 正常打开返回件，无修复或错误弹窗；查看第一页和部分表格。Word 滚动 API 返回窗口不可用，因此不声称完成 Word 全页视觉检查；全部三页视觉 QA 来自 LibreOffice 渲染。

## 复核体验与保存行为

- 导入处理结果后显示**修改后复核**入口：完成记录、待处理、新增 / 已更新、需确认位置的数量及下一步操作。
- 完成和未完成说明直接出现在批注卡片和复核窗口。较长对照滚动时，操作按钮仍留在弹窗底部。
- **逐条复核**优先查看需确认位置的待处理意见，随后逐条阅读；可切到当前文档，再返回对照继续。
- 完成记录为只读，不改目标、revision、状态或历史。已删除的完成目标不会显示旧路径上其他段落作为替代目标。
- 待处理意见出现多个候选时不默认绑定。用户明确确认位置后增加 revision、保留 `targetHistory`，意见仍待处理。较早回报显示为“上一版处理说明”。
- **新增 / 已更新**筛选沿用现有协议派生状态，不新增另一套完成状态；下一轮交接仍只要求处理待完成意见，完成记录保留。

真实浏览器流程涵盖导入返回结果 → 保留未保存草稿 → 读取真实修改后的 DOCX → 原定位保持 → 明确确认图注当前位置（revision 2、旧定位入历史）→ 只读复核已删除完成目标 → 新增整体意见 → 下载下一轮交接包 → 完整副本离线继续编辑。最终六条记录为四条完成、两条待处理；新增 / 已更新两条分别为新整体意见和确认位置后的图注。

macOS Chrome 154.0.8037.98、Edge 154.0.4258.62 完整流程通过，页面异常和外部 HTTP(S) 请求为空。工程浏览器测试使用 Playwright 和兼容文件选择器，不能描述为 Windows 真机或 computer use 的产品全流程实测。此前本机 file URL 的 computer use 限制仍遵守。

另验证完成的整体意见无需定位猜测、不会改变记录或丢失草稿。原有 HTML 完整导入 / 导出、UI / 动效、DOCX 文件关联及恢复、重载 / 回报生命周期、定位候选和本地网站检查通过。核心、CLI、Python 与协议测试 90 项通过。

## 性能测量与变化

Apple M5 Pro、macOS 25.5.0、原生 Chrome headless。优化前基准为 `dfcdc0a` 的单文件，优化后包含本轮复核及搜索缓存；每类各三轮，每次使用新浏览器，取中位数。操作耗时包含 Playwright 调度，系统文件 / 可执行文件缓存未清空，不代表严格冷启动。

| 样本 / 操作 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 2,000 段 HTML，完整预览导入 | 67.8 ms | 72.9 ms |
| 2,000 段 DOCX，完整预览导入 | 849.1 ms | 845.5 ms |
| 100 页 PDF，首屏导入 | 208.4 ms | 203.1 ms |
| 300 页 PDF，首屏导入 | 215.6 ms | 215.5 ms |
| 100 页 PDF，第二次全文搜索 | 44.1 ms | 7.0 ms |
| 300 页 PDF，第二次全文搜索 | 119.6 ms | 14.1 ms |
| 300 页 PDF，首次全文搜索 | 136.8 ms | 137.9 ms |

工作区首次就绪约 86–95 ms。没有观察到明显启动 / 首次导入改善，因此本轮没有引入延迟加载或宣传这部分加速。

单文件前版 6,924,852 字节，性能测量时优化版 6,934,061 字节。随后完善复核文案和固定操作区，最终 `index.html` 为 6,935,481 字节；搜索实现未再改变，未将这段界面变化后的文件描述为重新测了三轮性能。

重复搜索缓存精确提取字符串，最多 4,000,000 个 UTF-16 字符（字符串内容约 8 MB，另有容器开销）；超限淘汰，超大单页不缓存。文字项和坐标仍使用最多十二页的独立缓存。销毁文档会清空搜索缓存，轻量 JSON 和完整副本不写入缓存。100 / 300 页每次搜索完整得到 3,000 / 9,000 个命中；预算内重复搜索文本提取次数从 100 / 300 降为零。淘汰、计数和销毁检查通过。

连续滚动探针为二十次等待页面渲染的跳转，以及九十个动画帧的滚动增量；不是原生触控板实测。帧间隔 p95 约 16.7–16.8 ms，超过 34 ms 的帧数中位数为零。最多三张完整页画布，统计含一张指纹画布时总计四张、约 421 万像素。没有据此宣称滚动性能显著提升。

300 页滚动后主线程 JS 堆瞬时读数约 11.8 → 13.7 MB，未强制 GC，不包含 PDF Worker 或 GPU，不能称为整机峰值内存。PDF 样本为每页三十行文字的合成文档，未覆盖大量扫描图片性能；原有千页导入及 PDF 阅读 / 生命周期回归通过。
