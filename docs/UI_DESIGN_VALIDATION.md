2026-10-09，本地 `codex/pdf-review`。未 push、创建 PR、部署或更新发布资产；保留既有 HTML、DOCX、PDF 功能和产品名称。`videos/` 未修改。

## 设计决策

- 首页采用双栏编辑式构图：大标题、打开文档、体验示例，以及文档与批注的装饰性示意。支持格式、快捷打开和本地处理说明保留在可见位置；装饰图不进入辅助技术的阅读顺序。
- 暖白、深墨绿与铜色统一全站。渐变集中在首页光晕、强调文字和主要按钮；阅读区使用低干扰底色，文件内容保持原比例。
- 工作区统一间距、边框、圆角、按钮层级、批注卡片和设置页。源 CSS 选择器、视口尺寸留在数据和任务中，不出现在批注编辑区域。
- 保存副本支持正反向连续展开，快速关闭/重开不会重置到首帧。下拉菜单与弹窗采用小幅等比缩放，弹窗遮罩以透明度过渡，避免逐帧改变背景模糊半径。系统选择减少动画时直接切换状态。
- 打开弹窗前清理保存菜单，避免关闭中的菜单截走 Esc；面板关闭时恢复恰当焦点。窄屏保存菜单按视口边界校正，有批注后仍能访问打开、交接、保存和文件夹入口。

参考 [shadcn/ui](https://github.com/shadcn-ui/ui) 的组件层级、可访问性，以及 [Motion](https://github.com/motiondivision/motion) 的状态过渡思路。未复制这两个项目的代码或素材，未引入 React、动画库、外部字体或运行时请求；新增示意图由本项目 HTML/CSS 构成。

## 后续优化：范围与流程层级

2026-10-09，继续完成信息层级和范围提示两项。常规流程保留单行下一步提示；首次使用展示三步说明，收起详情或选择「以后精简显示」后使用已有本机偏好保存精简状态。随时可展开流程详情。缺少返回文档、定位需要确认、位置检查未完成时展开对应说明；用户输入和普通阶段变化不会反复重置手动开合状态。精简时隐藏与顶部交接、侧栏保存重复的按钮，返回文档和复核入口仍可直接操作。

修改意见旁增加可读的范围标记：整份文档、所选文字/元素/区域、具体页码；取消选择提示先选择且保留意见。整体模式不重复展示文件名卡片；局部选区默认显示两行摘要，可展开最多 600 字的已有摘要，完整定位与原文仍保留在数据里。编辑局部批注时回到浏览，标记仍显示其实际局部范围。没有目标时保留操作提示，有目标后收起重复说明。范围与计数仅在内容改变时更新播报节点，避免每次输入重复触发辅助技术提示。

流程面板按当前高度和透明度连续展开、反向收起；关闭期间内容 inert，焦点在被收起内容里时回到详情按钮。长摘要平滑调整高度，快速换目标取消旧高度动画；遵循系统减少动态效果偏好。完整副本清理临时范围和开合状态，打开时重新构建，没有更改批注协议或源文件。
