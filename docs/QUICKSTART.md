# HTML Review 快速开始

[完整说明](../README.md) · [English](../README.en.md) · [Windows / PowerShell](WINDOWS.md) · [agent 结果接口](AGENT_RESULTS.md)

## 1. 打开工具

在 [v0.1.0 页面](https://github.com/King-A23/html-review/releases/tag/v0.1.0) 下载 `html-review.html`，用现代桌面浏览器直接打开。无需安装或配置 AI 服务，推荐 Chrome 或 Edge。也可以下载或克隆源码，直接打开根目录 `index.html`。

只想体验时，点击**体验一份审阅示例**。自己的页面是独立 HTML 时，点击**打开 HTML**，也可直接拖入文件。带本地 CSS、图片或脚本时，点击顶部的**导入文件夹**，选择包含入口 HTML 和资源的目录，再选择入口。

工具只读取所选文件。选择文件夹会收录其中的文件，分享副本时这些资源也会一并分享；请选择只包含本页面所需文件的目录。

## 2. 写一条有明确目标的意见

| 模式 | 操作 | 适合的意见 |
| --- | --- | --- |
| 文字 | 拖选预览中的文字 | 将这句话改为指定文案，保留当前强调样式。 |
| 元素 | 点击图片、按钮、卡片；可选父级容器 | 将这张卡片的按钮与其他卡片底部对齐。 |
| 单页 | 点击已有幻灯片/打印页，或从页码列表选择 | 调整第 2 页的标题与图表间距。 |
| 整体 | 无需选区，直接写意见 | 窄于 720px 时改成单列，卡片间距 16px。 |
| 浏览 | 使用按钮、输入框和页内锚点 | 先检查页面交互，也可填写整个文件的意见。 |

填好意见后点击**保存批注**，或按 `Ctrl/⌘+Enter`。取消选择会保留已填写的意见。已有批注可**定位、编辑、删除**；编辑后点击**更新批注**。撤销和重做保留最近 50 次操作，刷新后不保留历史。

单页模式需要 HTML 本来就有分页或幻灯片结构；连续页面请使用元素或整体。布局意见可先用预览工具栏选择手机、平板或桌面视口，再保存批注。

## 3. 下载并交接

先保存批注，再点击**下载批注副本**。默认 `.review.html` 包含工具、原页面和资源快照以及批注，直接打开即可继续编辑。它不会覆盖原文件。

下载按钮旁还可选择：

- **压缩副本**：完整副本的 `.review.html.gz`，解压后打开。
- **轻量批注**：`.review.json`，包含完整意见和定位数据，不包含文件快照；交给 agent 时需同时提供原始 HTML 和资源，不能单独恢复编辑工作区。

点击**复制修改任务**可以取得可交接的任务文本，也需同时提供原始 HTML 和资源。工具不自动调用 agent；通用提示词见 [AGENT_PROMPT.md](../AGENT_PROMPT.md)。

需要脚本和示例时，可使用发布离线套件 `html-review-v0.1.0.zip`，或源码仓库。agent 先运行以下命令核对批注对应的原文件版本；脚本需要 Python 3：

```sh
python3 scripts/inspect_review.py report.review.json report.html
```

也支持完整 `.review.html` 与 `.review.html.gz`。只读取提取后的批注和元数据，不要把整个 HTML 副本或 Base64 放进 agent 上下文。

## 4. 查看修改，接收处理结果

agent 修改原 HTML 或资源后，点击预览右上角的**重载页面**，读取最新源内容并保留批注、草稿、模式和撤销历史。

Chrome、Edge 支持通过选择器建立只读文件/文件夹关联。拖入的文件、旧工作区及下载副本只带快照，首次重载需选择对应原文件；带资源时选择整个文件夹。刷新工具后可能要求重新授权。不支持持久文件访问的浏览器，每次重载需要再次选择。读取失败时会保留当前工作区。

agent 完成并验证后，可按批注 ID 回传：

```sh
python3 scripts/update_review.py report.review.json \
  --id "批注-ID" \
  --status resolved \
  --summary "已修改指定文案，并检查页面布局。" \
  --output report.review-results.json
```

将结果放在原 HTML 旁边：`report.html` 对应 `report.review-results.json`。**已关联文件夹**时，重载会同时读取该结果；仅关联单个 HTML 时没有相邻 JSON 的读取权限，可在列表点击**导入 agent 处理结果**。

回报更新处理状态和说明，保留原文、意见及定位。列表支持**全部记录、待处理、已完成**筛选；更新已处理的意见会重新进入待处理。新一轮只交付未完成意见。旧版本回报不能覆盖新意见，同一批结果重复导入不会重复追加历史。已完成是回报者标记的状态，仍需检查实际效果。更完整的说明与 JSON 协议见 [AGENT_RESULTS.md](AGENT_RESULTS.md)。

## 保存与支持范围

显示**本机已保存**后，同一标签刷新可恢复草稿；重新打开工具地址会提示恢复。每个工具地址只保留最近一个工作区，浏览器清理数据或存储不可用可能导致恢复失败。**本机保存不等于下载副本**，需要长期保留或跨设备使用时请下载。

仅打开可信 HTML。页面脚本可运行，网络资源仍可能联网。普通独立 HTML 和所选目录内的相对资源是主要支持范围；服务器接口、ES 模块依赖、嵌套 iframe、跨页跳转和需同源运行的应用可能无法完整重现。原始 HTML 上限 20 MiB，文件夹合计 50 MiB、最多 500 个文件，单资源 40 MiB，批注副本重新导入上限 100 MiB。完整协议与限制保留在 [README](../README.md)。
