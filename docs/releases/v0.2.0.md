# v0.2.0 · Public Beta

本版首次加入 DOCX / PDF 离线审阅。实际公开状态及下载资产见 [GitHub Releases](https://github.com/King-A23/html-review/releases)。

## 使用上的变化

- **打开文档**统一读取 HTML、Word（DOCX）和 PDF。DOCX 连续预览支持文字、元素和整体批注；PDF 原页预览支持文字、区域、单页及整体批注。
- **交给 agent**可复制任务或下载交接 ZIP，内含字节不变的原文档、HTML 资源、轻量批注及 `review/TASK.md`。需自行将材料附给 agent，工具不会自动发送或调用 AI。
- **保存副本**提供完整 `.review.html`、gzip 工作区和轻量 `.review.json`。DOCX / PDF 轻量批注可与哈希及字节数匹配的原文件配对恢复。
- **读取返回文件**分别接收修改后的文档和处理结果 JSON，再逐条复核。失败或取消保留工作区及草稿；回报只更新意见状态，不替代正文核查。
- HTML / DOCX / PDF 分别使用批注 schema 1 / 2 / 3；处理结果继续使用 `schemaVersion: 1`，旧回报不能关闭更新后的意见。

## 支持边界

DOCX 预览不还原 Word 分页与完整排版，不将意见写回为 Word 原生批注。复杂域、文本框、嵌入对象、修订和特殊格式可能展示不全。

PDF 暂无 OCR；扫描页使用区域批注。部分修改需要另附 DOCX、HTML 或设计稿等可编辑源，agent 应明确报告缺少材料，不能把未修改意见回报为完成。原文件上限 20 MiB，PDF 最多 1000 页；其他限制见[完整参考](../REFERENCE.md)。

本次准备未进行 Windows 实体机或实体手机测试。窄屏浏览器模拟不是手机实测；Windows / Linux CI 的配置也不是对应提交已通过的证据。

## 验收与发布

发布门槛为构建一致性、单元测试、`npm run test:documents` 的 17 套检查，以及实际 ZIP 解压后的运行与离线闭环。文档测试需 `tests/pdf-requirements.txt`、中文字体和 Poppler；浏览器可通过 `BROWSER_PATH` 指定，reading-tools 也支持 `BROWSER_CHANNEL`。实际执行结果以本次验收记录和对应 CI run 为准。
