# HTML Review v0.1.0 · Public beta

v0.1.0 是 HTML Review 的首个公开测试版，采用 [MIT 许可证](https://github.com/King-A23/html-review/blob/main/LICENSE)。

HTML Review 是本地 HTML 批注工具：在真实渲染页面上指出要改的文字、元素、单页或整体，下载可继续编辑的批注副本，或交给 coding agent 修改。工具独立运行，不自动调用 agent，也不写回原始文件。界面目前为中文。

## 本版功能

- **明确范围的反馈。** 对文字、元素、已有幻灯片/打印页或整个文件提出意见，保存原文、定位上下文和视口；源内容变化后可核对定位，有歧义时会提示。
- **可带走的审阅工作区。** 完整 HTML 副本包含工具、源文件及导入资源快照；另提供 gzip 压缩副本和轻量批注 JSON。批注可编辑、删除、撤销及重做。
- **本机恢复。** IndexedDB 保存当前工作区、未完成草稿和布局偏好；长期保留仍需下载副本。
- **读取真实源文件更新。** 关联原文件或目录后，重载最新 HTML 与资源，保留批注、草稿、当前模式和撤销历史。首次关联或权限失效时通过选择器授权读取。
- **agent 结果回传。** 按 ID 和意见版本更新待处理/已完成状态与说明，保留意见和目标；关联目录后重载同名结果 JSON，也可手动导入。拒绝旧版本回报并去重重复批次。
- **独立交接。** 复制任务、静态检查源版本及生成结果 JSON，不绑定特定 agent 或模型。提供可选命令行打开入口。
- **桌面审阅布局。** 左/右批注栏、手机/平板/桌面预览宽度、快捷键，以及遵循系统减少动态效果设置的界面。

## 开始一次审阅

打开工具 → 体验示例或导入 HTML/文件夹 → 选择范围并保存批注 → 下载副本或复制修改任务 → agent 修改原文件 → 重载源内容并导入处理结果。

操作细节见[快速开始](https://github.com/King-A23/html-review/blob/main/docs/QUICKSTART.md)，完整批注数据说明见 [README](https://github.com/King-A23/html-review/blob/main/README.md)，结果 JSON 协议见 [AGENT_RESULTS.md](https://github.com/King-A23/html-review/blob/main/docs/AGENT_RESULTS.md)。

## 已知限制

这是首个 public beta，面向现代桌面浏览器和普通独立 HTML。界面及数据接口可能继续调整。

- 仅导入可信 HTML。预览允许页面脚本运行，资源可能联网；sandbox 不是恶意文件分析环境。
- 不可靠支持服务器路由、接口、ES 模块依赖、嵌套 iframe、跨页导航或依赖同源能力的应用；文件夹导入不启动开发服务器。
- 单页批注依赖已有分页结构，不会给连续页面自动分页。Shadow DOM、canvas 或图片里的文字不能作为普通 DOM 文字定位。
- 浏览器策略可能影响目录读取和下载。下载副本不携带磁盘权限；不支持持久文件访问的浏览器每次重载需重新选择。
- 本机恢复依赖浏览器存储，没有多人协同。页面运行状态变化可能影响定位；批注副本保留源字节，不能完整保留运行时状态。
- 原始 HTML 限 20 MiB；目录合计 50 MiB、500 个文件，单资源 40 MiB；重新导入批注 HTML 限 100 MiB。
- agent 标记已完成不代表工具自动验证修改正确性。请核查实际修改，再保留新的批注副本。

## 校验下载文件

将两个资产与 `SHA256SUMS.txt` 放在同一目录。Linux 可运行 `sha256sum -c SHA256SUMS.txt`，macOS 可运行 `shasum -a 256 -c SHA256SUMS.txt`。Windows PowerShell 可用以下命令显示哈希，再与清单逐项比对：

```powershell
Get-FileHash .\html-review.html -Algorithm SHA256
Get-FileHash .\html-review-v0.1.0.zip -Algorithm SHA256
```

SHA-256 用于确认文件内容与发布清单一致，不是数字签名。
