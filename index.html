GETTING STARTED

把意见，说到点上。

三步完成一次清晰、可继续的审阅。

  1. 01

    打开，认真看一遍

    打开或拖入 HTML 或 DOCX；带相对图片、样式与脚本时，请导入文件夹。浏览模式可正常使用页面交互。

  2. 02

    选好范围，写下意见

    文字模式拖选原文；元素模式点击目标，也可向外选择父级。单页对应 HTML 中的幻灯片、打印页等分页区块，可点击选择或从列表挑选。整体对应整个文件。取消选择时，意见会保留。

  3. 03

    保存，交给下一步

    先保存批注，再下载副本或复制修改任务。HTML 副本可继续编辑；压缩副本需解压；轻量批注和复制的任务需连同原文件一起交付；HTML 还需附带资源。DOCX 使用连续内容预览，支持文字、元素和整体批注，不还原 Word 页码与排版，不修改原文件。打开 DOCX 轻量 JSON 后选择匹配的原文件可恢复批注。agent 可以回传处理结果 JSON；已关联文件夹时，重载会读取同名结果文件，也可在批注列表导入。完成记录会保留；修改已完成意见会重新进入待处理。

刷新可恢复本机草稿。原文件被修改后，点击预览右上角的重载按钮读取最新文档（HTML 包含关联资源），保留批注与草稿；首次可能需要选择原文件或文件夹。批注支持撤销与重做；存储不可用时请下载副本，避免遗失修改。

支持范围与文件限制

单页识别 data-page、data-slide、print-page、slide 以及多个 page 区块；没有分页结构时，请用整体或元素批注。仅打开可信 HTML。页面脚本可运行；服务器接口、嵌套 iframe、ES 模块等可能无法完整重现。原始 HTML / DOCX 上限 20 MiB，副本上限 100 MiB；目录上限 50 MiB、500 个文件。DOCX 解压内容限 100 MiB、3000 项；转换可取消，超过 30 秒中止。页眉页脚和复杂图形不保证呈现；原生 Word 批注不转为任务。
