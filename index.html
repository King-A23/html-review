GETTING STARTED

把意见，说到点上。

三步完成一次清晰、可继续的审阅。

  1. 01

    打开，认真看一遍

    打开或拖入 HTML；带相对图片、样式与脚本时，请导入文件夹。浏览模式可正常使用页面交互。

  2. 02

    选好范围，写下意见

    文字模式拖选原文；元素模式点击目标，也可向外选择父级。单页对应 HTML 中的幻灯片、打印页等分页区块，可点击选择或从列表挑选。整体对应整个文件。取消选择时，意见会保留。

  3. 03

    保存，交给下一步

    先保存批注，再下载副本或复制修改任务。HTML 副本可继续编辑；压缩副本需解压；轻量批注和复制的任务需连同原 HTML、资源一起交付。agent 可以回传处理结果 JSON；已关联文件夹时，重载会读取同名结果文件，也可在批注列表导入。完成记录会保留；修改已完成意见会重新进入待处理。

刷新可恢复本机草稿。原文件被修改后，点击预览右上角的重载按钮读取最新 HTML 和资源，保留批注与草稿；首次可能需要选择原文件或文件夹。批注支持撤销与重做；存储不可用时请下载副本，避免遗失修改。

支持范围与文件限制

单页识别 data-page、data-slide、print-page、slide 以及多个 page 区块；没有分页结构时，请用整体或元素批注。仅打开可信 HTML。页面脚本可运行；服务器接口、嵌套 iframe、ES 模块等可能无法完整重现。原始 HTML 上限 20 MiB，副本上限 100 MiB；目录上限 50 MiB、500 个文件。
